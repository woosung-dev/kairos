```
## Kairos 가 뭔지

회의 녹음, 노트, 자료를 던져 넣으면 AI 가:
- 회의 음성 → 30초 안에 화자별 요약 + Action Item 자동 추출
- 노트 → 의미 단위로 자동 정리 + 임베딩
- ⌘K 자연어 검색 → "지난주 마케팅 회의에서 OO 가 뭐라고 했지?" 같은 질문에 인용 + 답변

세컨드 브레인 + AI 미팅 어시스턴트 의 결합입니다.

## 왜 5명 한정인지

- 1인 운영이라 동시 사용자 많아지면 응답 늦어집니다 (RAG 답변 평균 10초 — 빠른 속도가
  아닙니다. 정확도 우선 단계)
- 현재 dev Clerk 인증 환경 (Production 키 미발급 — Google/Email 로그인은 됩니다.
  비즈니스 계정은 아직 X)
- 무료 베타 — 결제/플랜은 dogfooding 후 단계적 도입

## 부탁드리고 싶은 것

1. 회의 1개 또는 노트 3-4개 넣어보기 (5-10분)
2. ⌘K 로 자연어 검색 1-2번 시도
3. 30분 안에 솔직한 첫인상 + 막힌 곳 알려주기 (좋아도, 별로여도, 한 줄이라도)

## 주의사항

- 현재는 dev 환경 → 데이터가 유실되지 않게 백업은 하지만, 운영 GA 전이라 "운영 등급 SLA"
  는 약속 못 드립니다
- 회의 녹음을 업로드하면 OpenAI Whisper (음성→텍스트) + Google Gemini (요약) 가 한 번
  call 됩니다. 민감한 회의는 우선 피해주세요 (정책: ADR-022 참조)
- 발견하신 버그/이상은 Sentry 로 자동 수집 외에, [Slack/Discord 채널 또는 메일]
  으로 직접 알려주시면 빠르게 fix 합니다

회신 주시면 가입 링크 + 첫 사용 가이드 보내드릴게요.

감사합니다,
[이름]
```
