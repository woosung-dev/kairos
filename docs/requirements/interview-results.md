## S5 측정 — "통합 도구로 대체 어려움" 응답률

**목표: ≥60%**

| 인터뷰이 | 역할 | "대체 어려움" 응답 | 주요 발언 |
|---------|------|-----------------|---------|
| 인터뷰이-01 | (미확인) | **부분 가능** | "일부는 가능하지 않을까 생각한다. 개인의 사용의 경우" |

**집계**
- 응답자 수: 0명(명확 "어렵다") / 총 1명 = **0%** (현재)
- 목표 달성 여부: 데이터 부족 (목표 5-10명 미충족)

> [!NOTE] S5 판정 기준 검토
> 인터뷰이-01의 응답은 "개인 사용 한정으로 부분 대체 가능"으로 해석.
> 팀 협업·지식 누적 맥락에서는 대체 여부 미확인 → S5 N으로 잠정 분류.
> 추가 질문으로 팀 사용 시나리오 탐색 권장.

**주요 원 발언**

> "일부는 가능하지 않을까 생각한다. 개인의 사용의 경우" — 인터뷰이-01

## S6 측정 — 페르소나-Wedge 분화

**목표: 1순위 Wedge ≥2개 분화**

| 페르소나 | 관찰된 1순위 Wedge | 근거 발언 |
|---------|-----------------|---------|
| PERSONA-001 (WS) | W3 (프로젝트 RAG Q&A) | (기존 자기확인) |
| PERSONA-002 (김PM) | (인터뷰 후 확정) | |
| PERSONA-003 (박PM) | (인터뷰 후 확정) | |
| 인터뷰이-01 | **W1 + W3 복합** | "W3은 강력해보이고, W1은 빠르게 써보고 싶다" |

**분화 현황 (2026-05-12)**
- W3 강하게 인상 → 설득력 있는 Wedge
- W1 즉시 사용 의향 → 온보딩 전환 Wedge
- 인터뷰이-01: W1·W3 모두 관심. 1순위는 **W1** (빠른 사용 의향 기준)
- 현재: W3(기존) + W1(신규) = 2개 분화 가설 유지

> [!NOTE] Wedge 해석
> 인터뷰이-01이 W1·W3을 모두 매력적으로 본 것은 긍정 신호.
> "강력해 보인다(W3)"는 인식 가치, "빠르게 써보고 싶다(W1)"는 행동 의향.
> S6 분화 확인을 위해 추가 인터뷰에서 1순위 단일 선택 유도 권장.
