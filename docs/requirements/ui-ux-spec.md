## 1. 레이아웃 — C|D 2-Panel (ADR-006 §3)

```
┌──────────────────────────────────────────────────────────────┐
│  Header: [≡] 워크스페이스명    [🔍 검색... Cmd+K]    [프로필] │
├──────────────┬───────────────────────────────────────────────┤
│              │                                               │
│  사이드바     │           메인 콘텐츠 영역                     │
│  (220px)     │           (flex-1)                            │
│              │                                               │
│  📥 Inbox(N) │  Today 피드 / 프로젝트 상세 / 회의 상세 등     │
│  ──────────  │                                               │
│  내 프로젝트  │  ┌─────────────────────────────────────┐     │
│  ├ CMS 고도화│  │  RAG 오버레이 (Cmd+K 슬라이드)       │     │
│  ├ 보안 인프라│  │  검색바 + 대화 + 인라인 출처          │     │
│  └ + 프로젝트 │  └─────────────────────────────────────┘     │
│  ──────────  │                                               │
│  탐색        │                                               │
│  ├ 전체 공개  │                                               │
│  └ 태그별    │                                               │
│              │                                               │
└──────────────┴───────────────────────────────────────────────┘
```

- **사이드바 (220px):** 프로젝트 네비게이션 + 소스 트리. 프로젝트 클릭 시 하위 회의/노트/파일 펼침.
- **메인 콘텐츠 (flex-1):** 라우트에 따라 변경.
- **RAG (380px 오버레이):** 상단 검색바 항상 노출 + Cmd+K로 슬라이드 오버레이. 기존 3-Panel 상시 패널 **제거**.
- **기존 대비 변경:** 3-Panel(사이드바+메인+RAG) → 2-Panel(사이드바+메인) + RAG 오버레이.

## 4. 주요 인터랙션 패턴

### 4.1 홈 — 조건부 Today 피드 (ADR-006 §1)

사용자 상태에 따라 홈 화면이 분기한다:

| 상태 | 홈 화면 |
|------|---------|
| **신규/콘텐츠 적음** | 온보딩 배너: "첫 회의를 녹음하세요" / "빠른 메모를 작성하세요" CTA |
| **활성 사용자** | Today 피드: Inbox 미처리 알림 → 마감 액션 → AI 인사이트 → 최근 활동 |

- RAG 검색: Cmd+K 또는 상단 검색바로 **어디서든** 접근 가능.
- Today 피드 구성 (실제 구현):
  1. **Inbox 알림 카드** — 미처리 건수 표시
  2. **마감 액션 리스트** — 오늘 마감 기준, 완료/미완료 표시
  3. **AI 인사이트 카드** — "지난주 대비 회의 시간 30% 감소" 등
  4. **최근 활동** — 회의/노트/액션 아이템 시간순

### 4.2 Inbox — 스마트 일괄 처리 (ADR-006 §7)

```
┌───────────────────────────────────────────────────┐
│  Inbox                                    [설정⚙️] │
├───────────────────────────────────────────────────┤
│                                                   │
│  ⚠️ 확인 필요 (신뢰도 < 90%)                       │
│  ┌─────────────────────────────────────────┐     │
│  │ 📄 CMS 보안 회의록                       │     │
│  │    AI 추천: CMS 고도화 (72%)  [수정] [확정]│     │
│  └─────────────────────────────────────────┘     │
│                                                   │
│  ✅ AI 자동 처리 (신뢰도 ≥ 90%)                     │
│  ┌─────────────────────────────────────────┐     │
│  │ 📄 인프라 주간 리뷰 → 보안 인프라 개선 (95%) │     │
│  │    [✏️수정] [↩되돌리기]                    │     │
│  └─────────────────────────────────────────┘     │
│                                                   │
└───────────────────────────────────────────────────┘
```

- **2그룹 분리:** 신뢰도 임계값(기본 90%, 사용자 조절 가능) 기준.
- **자동 확정:** ≥ 90%이면 AI가 프로젝트 연결 + 태그 자동 확정. 사용자에게 알림만.
- **되돌리기:** 자동 확정된 항목도 수정/되돌리기 가능.
- **일괄 처리:** 확인 필요 그룹에서 다건 선택 → 일괄 확정/무시.

### 4.3 프로젝트 상세 — 대시보드형 (ADR-006 §6)

```
┌───────────────────────────────────────────────────┐
│  CMS 고도화                     [Active 🟢] [⋯]   │
├───────────────────────────────────────────────────┤
│                                                   │
│  💡 AI 프로젝트 인사이트 (L3)                       │
│  "3주 연속 일정 지연. 보안 검토가 병목입니다."        │
│                                                   │
├────────────────────────┬──────────────────────────┤
│  📋 회의 / 노트         │  ✅ 액션 아이템            │
│  ┌──────────────────┐  │  ☐ 킥오프 미팅 조율       │
│  │ 보안 회의 (4/3)   │  │    👤 당근님  🔴 High    │
│  │ 인프라 리뷰 (4/1) │  │  ☐ AWS 전환 제안         │
│  │ 📝 설계 노트      │  │    👤 사부님  🟡 Med     │
│  └──────────────────┘  │                          │
│                        │  📤 내보내기 / 가져오기     │
└────────────────────────┴──────────────────────────┘
```

- **최상단:** L3 프로액티브 인사이트 (AI 자동 종합).
- **2컬럼:** 좌(회의+노트, 시간순) / 우(액션 아이템 + 내보내기 허브).
- **콘텐츠 3개 미만:** 온보딩 뷰 전환 ("첫 회의를 녹음하세요").
- **프로젝트 상태:** Active / Completed / Archived (PARA 4분류 아님).

### 4.4 회의 상세 — 3뷰 전환 (ADR-006 §8)

```
┌───────────────────────────────────────────────────┐
│  [요약✓]  [트랜스크립트]  [액션]                     │
├───────────────────────────────────────────────────┤
│                                                   │
│  📋 AI 요약 (L1 + L2)                              │
│  "협회 IT 문제 해결을 위한 3개 프로젝트 킥오프 [1]"  │
│  "CMS 보안 검토 일정 확정 [2], AWS 전환 논의 [3]"   │
│                                                   │
│  🔑 핵심 결정사항                                   │
│  • CMS 보안 검토 → 4/10까지 완료 [1]               │
│  • AWS 전환 제안서 → 4/15까지 작성 [2]              │
│                                                   │
│  프로젝트: 🏷️ CMS 고도화 | 🏷️ 보안 인프라 개선     │
│                                                   │
└───────────────────────────────────────────────────┘
```

- **요약 (기본 뷰):** L1 요약 + L2 결정사항/액션. 인라인 출처 [1][2][3] 색상 구분 (cyan/purple/amber). 클릭 시 해당 소스의 인용문 스니펫이 펼쳐지며 화자·타임스탬프 표시.
- **트랜스크립트:** 전체 원문 + 출처 마커 하이라이트 + 검색 (스켈레톤 구현).
- **액션:** 진행률 바 (X/Y 완료) + 체크박스 목록. 담당자·기한·소스 연결. 기한 초과 시 빨간 강조.

### 4.5 RAG — 인라인 출처 + 소스 뷰어 (ADR-006 §2, §4)

```
[사용자] "CMS 보안 관련 결정 사항이 뭐였지?"

[AI 답변]
"CMS 보안 검토 일정은 4/10까지 완료하기로 결정했습니다 [1].
 AWS 전환은 보안 검토 완료 후 진행합니다 [2].
 예산은 기존 인프라 비용 내에서 조정합니다 [3]."

 [1] 보안 회의 (4/3)  [2] 인프라 리뷰 (4/1)  [3] 예산 회의 (3/28)
 
 [복사] [노트로 저장] [내보내기]
```

- **인라인 출처:** [1][2][3] 색상 구분 (teal/purple/amber).
- **[1] 클릭:** 메인 영역에 소스 뷰어 열림 + 원문 하이라이트 + 자동 스크롤.
- **소스 범위:** 3단계 스코프 선택 (전체 워크스페이스 / 현재 프로젝트 / 선택한 소스).
- **응답 하단 액션:** 복사 / 노트로 저장 / 내보내기.

### 4.6 콘텐츠 추가 — 빠른 메모 + 외부 가져오기 (ADR-006 §9)

"입구는 여러 개, 파이프라인은 하나"

| 입력 방식 | 설명 |
|----------|------|
| **빠른 메모** | 플레인 텍스트 입력 (textarea). Tiptap 미사용 — 마찰 최소화 우선. |
| **회의 녹음 업로드** | `/new` 페이지에서 MP3/WAV/M4A/MP4/WebM 드롭존 → presigned URL → R2 (구현됨) |
| **텍스트 붙여넣기** | 클립보드에서 직접 붙여넣기 (Sprint 2+) |
| **URL 가져오기** | 외부 링크 → 콘텐츠 추출 (Sprint 2+) |

- 모든 입력 → 동일한 AI 파이프라인 (STT/요약/액션/임베딩) 통과.
- `/new` 페이지: 3가지 콘텐츠 타입 카드 (회의 녹음 ✅ / 노트 작성 예정 / 자료 업로드 예정).
- 회의는 "콘텐츠 추가"의 옵션 중 하나. 프로젝트 상세가 핵심 화면.

### 4.7 Archive 전환

```
[프로젝트 상세 → 상태 변경 → "Archived"]
  → 확인 모달:
     "CMS 고도화 프로젝트를 Archive합니다."
     ☑ AI 인사이트 자동 추출 (L3)
     ☑ 팀 전체에 공개 (RAG 검색 포함)
     [취소] [Archive]
```

- 프로젝트 상태 전환: Active → Completed → Archived.
- Archive 시 AI가 핵심 인사이트를 자동 추출하여 조직 지식에 축적.
- Archive된 프로젝트도 RAG 검색 대상에 포함.

## 5. 내보내기/가져오기 허브 (ADR-006 §5)

NotebookLM 스튜디오를 대체하는 경량 허브.

| 방향 | 포맷 |
|------|------|
| **내보내기** | Markdown / 프롬프트 복사 / JSON / PDF |
| **가져오기** | 파일 업로드 / 텍스트 붙여넣기 / URL |

**플라이휠:** Kairos에서 정리 → 외부에서 생성 → Kairos에 저장 → RAG 검색.

## 6. 페이지별 라우트 (실제 구현 기준)

```
/                              → Today 피드 (홈)
/(auth)/sign-in                → 로그인 (Google OAuth + 이메일/비밀번호)
/(auth)/sign-up                → 회원가입 (동일)
/inbox                         → Inbox 스마트 일괄 처리
/new                           → 콘텐츠 추가 (회의 업로드 / 노트 / 자료)
/notes                         → 빠른 메모 목록 + 작성
/projects/[id]                 → 프로젝트 대시보드 (L3 인사이트 + 2컬럼)
/meetings/[id]                 → 회의 상세 (요약/트랜스크립트/액션 3뷰)
/search                        → 검색 (모바일 RAG 진입점)
/dashboard                     → (레거시, 빈 페이지 — 추후 제거)
```

> **참고:** PRD의 `/workspace/[workspaceId]/projects/[projectId]/` 네스팅 대신 플랫 라우트로 구현.
> 워크스페이스 ID는 `useWorkspaceStore` (Zustand)로 전역 관리.

**제거된 라우트 (PARA 시대):**
- ~~`/areas/[paraId]/`~~ → 제거 (ADR-004)
- ~~`/resources/[paraId]/`~~ → 제거
- ~~`/archives/`~~ → 사이드바 Archive 섹션으로 대체
- ~~`/weekly-review`~~ → MVP 범위 외
- ~~`/ask/`~~ → RAG 오버레이 (Cmd+K)로 통합
