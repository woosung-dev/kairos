## 1. 레이아웃 — 3-Panel 구조

```
┌──────────────────────────────────────────────────────────────────────┐
│  Header (Clerk 프로필 + 워크스페이스 전환)                            │
├────────────────┬───────────────────────────────┬─────────────────────┤
│                │                               │                     │
│  좌측 사이드바  │      메인 콘텐츠 영역          │  우측 RAG 패널       │
│  (고정 240px)  │      (flex-1)                 │  (토글, 360px)      │
│                │                               │                     │
│  📥 Inbox (N)  │  회의록 / 노트 / 칸반         │  자연어 질문 입력    │
│  ────────────  │  뷰 렌더링                    │  + Claude 답변      │
│  🎯 Projects   │                               │                     │
│  📌 Areas      │                               │  프로젝트/영역 범위  │
│  📚 Resources  │                               │  선택 가능           │
│  🗄️ Archives   │                               │                     │
│  ────────────  │                               │                     │
│  Weekly Review │                               │                     │
│  바로가기      │                               │                     │
│                │                               │                     │
└────────────────┴───────────────────────────────┴─────────────────────┘
```

- **좌측 사이드바**: 프로젝트 네비게이션, 항상 표시, 접힘 지원
- **메인 콘텐츠**: 라우트에 따라 변경 (Inbox 뷰, 회의 상세, 칸반 등)
- **우측 RAG 패널**: 기본 숨김, 버튼 클릭으로 슬라이드 인/아웃

## 4. 주요 인터랙션 패턴

### 4.1 Inbox → 프로젝트 연결 확정

```
[Inbox 아이템 카드 목록]
  → 아이템 클릭
  → 슬라이드업 패널 열림
     ├── AI 추천 프로젝트 뱃지 표시 (confidence % 포함)
     ├── 프로젝트 선택 (Project / Area / Resource)
     ├── 기존 프로젝트 검색 또는 새로 생성
     ├── N:M 다중 선택 가능
     └── [분류 확정] 버튼 → is_processed=true
```

- AI 추천 confidence가 높을수록 뱃지 강조
- 분류 확정 시 Inbox에서 사라지고 해당 프로젝트에 연결됨

### 4.2 칸반 보드 (액션 아이템)

```
┌──────────────┬──────────────┬──────────────┐
│   To Do      │ In Progress  │    Done      │
├──────────────┼──────────────┼──────────────┤
│ ┌──────────┐ │ ┌──────────┐ │ ┌──────────┐ │
│ │ 액션 1   │ │ │ 액션 3   │ │ │ 액션 5   │ │
│ │ 👤 당근  │ │ │ 👤 사부  │ │ │ 👤 튜닝  │ │
│ │ 🔴 High  │ │ │ 🟡 Med   │ │ │ ✅ Done   │ │
│ │ 📅 3/25  │ │ │ 📅 4/01  │ │ └──────────┘ │
│ └──────────┘ │ └──────────┘ │              │
│ ┌──────────┐ │              │              │
│ │ 액션 2   │ │              │              │
│ └──────────┘ │              │              │
└──────────────┴──────────────┴──────────────┘
```

- **drag-and-drop** 상태 변경 (@dnd-kit)
- 담당자 아바타 인라인 표시
- 리스트 뷰 전환 지원

### 4.3 회의 상세 페이지

```
┌──────────────────────────────────────────────────┐
│ [AI 요약 카드]                                    │
│  "협회 IT 문제 해결을 위한 3개 프로젝트 킥오프"     │
│  프로젝트: 🎯 CMS 고도화 | 📌 보안 인프라 개선     │
├──────────────────────────────┬───────────────────┤
│ [트랜스크립트 뷰어]          │ [액션 아이템 패널]  │
│  00:00 Speaker A: ...       │  ☐ 킥오프 미팅 조율 │
│  00:32 Speaker B: ...       │    👤 당근님        │
│  01:15 Speaker A: ...       │  ☐ AWS 전환 제안    │
│  (타임스탬프 클릭 → 재생)    │    🔴 High         │
└──────────────────────────────┴───────────────────┘
```

- 상단: AI 요약 카드 + 프로젝트 연결 뱃지
- 좌측: 화자 분리 타임스탬프 트랜스크립트 (클릭 시 해당 시점 오디오 재생)
- 우측: 액션 아이템 패널 (칸반 미니뷰)

### 4.4 Archive 전환

```
[Project 상세 → "Archive로 이동" 클릭]
  → 확인 모달:
     "CMS 고도화 프로젝트를 Archive로 이동합니다."
     ☑ 내부 메모를 Resource로 보존
     ☑ 회의록을 Resource로 보존
     [취소] [Archive로 이동]
```

## 5. 페이지별 라우트

```
/                          → 대시보드 리다이렉트
/(auth)/sign-in            → Clerk 로그인
/(auth)/sign-up            → Clerk 회원가입
/dashboard                 → 홈 대시보드 (최근 활동, Inbox 미처리 수)
/inbox                     → Inbox 뷰 + 분류 워크플로우
/weekly-review             → Weekly Review 가이드 뷰
/workspace/[id]/
  ├── projects/[paraId]/
  │   ├── meetings/        → 회의록 목록
  │   ├── meetings/[id]    → 회의 상세 (요약 + 트랜스크립트 + 액션)
  │   ├── notes/           → 노트 에디터 (Tiptap)
  │   ├── actions/         → 칸반 / 리스트 뷰
  │   ├── files/           → 첨부파일
  │   └── ask/             → RAG 채팅
  ├── areas/[paraId]/      → Areas 워크스페이스 (동일 구조)
  ├── resources/[paraId]/  → Resources 워크스페이스
  └── archives/            → Archive 뷰 + 재활용 UX
```
