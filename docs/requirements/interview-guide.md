# 인터뷰 가이드 — 프로젝트·워크스페이스 7필드 우회 질문

ADR-011 §2의 7개 핵심 필드를 고객 인터뷰에서 직접 묻지 않고 자연스럽게 파악하는 질문 모음.

## 배경

직접 질문("프로젝트 이름이 뭐예요?")은 인터뷰이를 제품 설계자로 만든다.
아래 우회 질문은 실제 사용 행동을 관찰하여 필드 설계 근거를 얻는다.

## 필드별 우회 질문

| 필드 | 직접 질문 (금지) | 우회 질문 |
|------|----------------|----------|
| `project.name` | "프로젝트 이름이 뭐예요?" | "동료에게 이 업무를 설명할 때 뭐라고 부르나요?" |
| `project.visibility` | "공개/비공개가 필요한가요?" | "팀 외부 사람이 이 자료를 보면 곤란한 경우가 있나요?" |
| `project.default_assignee` | "기본 담당자가 필요한가요?" | "새 태스크가 생기면 보통 누가 제일 먼저 보나요?" |
| `workspace.name` | "워크스페이스 이름이 뭐예요?" | "일하는 팀/부서를 어떻게 부르시나요?" |
| `workspace_member.role` | "관리자/멤버 구분이 필요한가요?" | "누가 사람을 추가하거나 뺄 수 있나요? 혼자서만 하나요?" |
| `project_member.role` | "프로젝트 권한 레벨이 필요한가요?" | "프로젝트에서 결정권이 있는 사람과 참고용으로만 보는 사람이 다른가요?" |
| `meeting.workspace_id` | "회의가 어느 프로젝트에 속하나요?" | "이 회의 내용을 나중에 어디서 찾을 것 같아요?" |

## 인터뷰 팁

- 질문 후 최소 7초 침묵 유지 (답변 강요 금지)
- "왜요?"를 3회까지 이어서 물어볼 것
- 사용 중인 도구(Notion, Slack 채널명 등)를 현장에서 보여달라고 요청
