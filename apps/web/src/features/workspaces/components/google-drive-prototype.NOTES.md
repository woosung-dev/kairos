# Google Drive UI prototype

질문: Google Drive를 단순 파일 업로드가 아니라 선택형 팀 지식 소스로 넣을 때, 설정 화면의 올바른 정보 구조는 무엇인가?

개발 환경에서 `http://localhost:3000/settings?tab=integrations&variant=A`로 시작한다.

- `A`: 권한과 선택 범위를 먼저 이해시키는 연결 카드
- `B`: 연결 → 선택 → 팀 지식화의 단일 가져오기 흐름
- `C`: 연결 이후 지식 소스의 최신성·범위·상태를 관리하는 현황 화면

이 UI는 OAuth, Google Picker, API 호출, 영속화를 전혀 수행하지 않는다. 선택 결과는 사용자 피드백 후 실제 기능의 ADR/설계로 흡수하고, 이 파일과 프로토타입 컴포넌트는 삭제한다.

- 2026-07-30: 카피는 v0의 Google Docs 전용·파일 단위 선택 범위에 맞췄고, 사용자 피드백 후 프로토타입을 삭제하는 조건은 그대로다.
