AI 자동 확정 임계값 90%
50% (느슨) 100% (엄격)

이 값 이상의 신뢰도를 가진 Inbox 항목은 AI가 자동으로 프로젝트에 연결합니다.
낮출수록 자동 확정이 많아지고, 높일수록 사용자 확인이 많아집니다.

A. 슬라이더

드래그로 직관적 조절. 실시간 미리보기 가능. 값의 범위를 시각적으로 인지

AI 자동 확정 임계값

90% 이상 신뢰도의 항목이 자동 확정됩니다.
낮은 값 = 자동 처리 많음 · 높은 값 = 수동 확인 많음

B. 프리셋 버튼

미리 정해진 4개 값(70/80/90/95) 중 선택. 사용자가 잘못된 값을 넣을 위험 없음

AI 자동 확정 임계값
%

직접 숫자를 입력하거나 ▲▼ 버튼으로 5% 단위 조절

C. 숫자 입력

정확한 값 입력 가능. 하지만 범위 인지가 어렵고, 잘못된 값(예: 200%) 입력 위험
